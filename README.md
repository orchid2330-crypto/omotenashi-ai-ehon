# 社長、AIを導入したのに、なぜ？ ― おもてなしの学校 デジタル絵本

シーキューブ株式会社「おもてなしの学校」のWeb絵本です。
HTML・CSS・JavaScript だけで作った静的サイトなので、GitHub Pages で無料公開できます。
APIキー・会員登録・データベースは使いません。

## できること

- 表紙 → 物語10ページ → 終わりのページ（最後の問いと「組織知チェックへ」ボタン）
- パソコン・タブレット横向き：左に文章、右に絵
- スマートフォン：上に絵、下に文章（大きめの文字）
- 絵は切り取らず、全体を表示
- 「自動で読む」：日本語の音声で読み上げ、読み終えると次のページへ自動で進む
- 「一時停止」「再開」「前へ」「次へ」「最初から読む」「音声オン／オフ」
- 音声が使えない端末では、自動で「音声なしの自動ページ送り」に切り替わり、画面にお知らせが出ます
- キーボード操作：← →（ページ移動）、スペース（自動で読んでいる間の一時停止・再開）
- スマートフォンでは左右のスワイプでもページを移動できます

## ファイルの構成

```
index.html     … 画面の骨組み（GitHub Pagesはこのファイルを最初に表示します）
story.json     … 文章・タイトル・問い・リンク先（文章を直すときはここだけ）
css/style.css  … 色・文字の大きさ・レイアウト
js/app.js      … ページ送り・読み上げなどの動き
images/        … 絵本の画像 page-01.webp 〜 page-10.webp（ファイル名は変えないでください）
```

## 組織知チェック（診断アプリ）のURLを設定する場所

`story.json` の上のほうにある `diagnosisUrl` に、診断アプリの公開URLを入れてください。

```json
"diagnosisUrl": "https://ここに診断アプリのURL/",
```

- 空欄（`""`）のままだと、終わりのページのボタンは「組織知チェックへ（準備中）」と表示され、押せない状態になります。
- `homeUrl` は「おもてなしの学校HPへ戻る」ボタンのリンク先です。
- URLは `https://` から始まる形で入れてください。

GitHubの画面で直接直す場合：リポジトリで `story.json` を開く → 右上の鉛筆マーク（Edit）→ 書き換える → 「Commit changes」。数分でGitHub Pagesにも反映されます。

## パソコン（Windows）で試す方法

`index.html` をダブルクリックで開くと、ブラウザの安全機能により `story.json` が読み込めず、
「絵本のデータを読み込めませんでした」と表示されることがあります。次のどちらかの方法で開いてください。

### 方法1：Python を使う（おすすめ）

1. このフォルダをエクスプローラーで開きます。
2. 上のアドレス欄に `cmd` と入力して Enter を押すと、黒い画面（コマンドプロンプト）が開きます。
3. 次のように入力して Enter を押します。

   ```
   python -m http.server 8000
   ```

   ※「python が見つかりません」と出たら、Microsoft Store で「Python」をインストールしてからもう一度試してください。
4. Chrome または Edge で `http://localhost:8000/` を開きます。
5. 終わるときは、黒い画面で `Ctrl + C` を押して閉じます。

### 方法2：Visual Studio Code の「Live Server」を使う

VS Code にこのフォルダを開き、拡張機能「Live Server」を入れて、`index.html` を右クリック →「Open with Live Server」。

## GitHub Pages で公開する手順

1. GitHub でこのリポジトリを開きます。
2. 公開したい内容が `main` ブランチに入っていることを確認します（作業用ブランチの場合は、プルリクエストを作って `main` に取り込みます）。
3. 上のメニューの「Settings」→ 左側の「Pages」を開きます。
4. 「Build and deployment」の「Source」で「Deploy from a branch」を選びます。
5. 「Branch」で `main`、フォルダは `/ (root)` を選び、「Save」を押します。
6. 1〜5分ほど待つと、同じ画面の上部に公開URL（例：`https://ユーザー名.github.io/omotenashi-ai-ehon/`）が表示されます。
7. そのURLをパソコンとスマートフォンで開き、表示と読み上げを確認してください。

## 読み上げについての注意

- 読み上げには、端末のブラウザに入っている音声（Web Speech API）を使います。声の種類や読み方は、端末やブラウザによって違います。
- ブラウザの決まりにより、音声はボタンを押したあとにだけ始まります。ページを開いただけで勝手に再生されることはありません。
- iPhone で音が出ない場合は、本体の音量やマナーモード（消音スイッチ）を確認してください。
- 日本語の音声がない端末では、音声なしの自動ページ送りに切り替わります。
- 一時停止して再開すると、読んでいた文の頭から読み直します。

## 動作確認したこと

- 画面サイズ：パソコン（1440×900、1280×680）、タブレット横・縦（1024×768、768×1024）、スマートフォン縦・横（390×844、844×390）で、絵が切れずに表示されること
- 自動読み上げ → 自動ページ送り → 最後の問いを読んで停止、一時停止・再開、自動中の手動ページ送り（音声が二重に流れないこと）
- 日本語音声がない環境での「音声なし自動ページ送り」への切り替えとお知らせ表示
- キーボード操作、`file://` で開いたときのお知らせ表示
